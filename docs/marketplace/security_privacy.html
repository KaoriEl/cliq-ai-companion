Your Code, Your Control

Privacy is a core tenet of Cliq. We ensure your development environment stays secure:

Local Processing

The Cliq IDE Server runs exclusively on 127.0.0.1. It is not accessible from the external network. All communication between the IDE and your CLI agent happens locally on your machine.

Token-Based Authentication

Every time you launch a Cliq session, a unique, high-entropy security token is generated. Only agents launched through Cliq can access the MCP server tools, preventing unauthorized access from other local processes.

No Hidden Tracking

Cliq does not send your source code to any external servers. Your code only goes to the CLI agent you have explicitly configured and launched. We respect your .gitignore and project trust settings by default. This includes diffs built for the Generate Commit Message action: the diff is only placed into the Cliq chat input, and is sent to an agent only when you explicitly choose to send it.
